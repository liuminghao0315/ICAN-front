# 全量字段（分析页面抓包） · 字段产出标注

> 说明：每个字段都用 `▆中文释义 [来源·标签]` 的形式标注，便于设计标注数据表时识别哪些是"机器可算的"、哪些是"业务系统字段"、哪些是"必须人工标注的"。
> 字段映射结论已交叉核验过 Python（视频处理.py / 音频处理.py / deepseek_evidences.py / task_runner.py）和 Java（AnalysisResult 实体 / AnalysisResultServiceImpl / AlgorithmResultListener）双侧源码。

## 图例

| 标签 | 含义 | 典型来源 |
|---|---|---|
| `[系统]` | Java 工程层产出/落库的系统字段 | id、taskId、videoId、videoUrl、URL/MinIO、时间戳 |
| `[元数据]` | 上传/导入时由用户或抓取脚本填入，Java 落库 | fileName、duration、uploadSource、sourceUrl |
| `[CV]` | Python 视觉模块（视频处理.py）产出，模型/规则推理 | OpenCV 帧统计、YOLO-World、人脸检测、场景判别 |
| `[ASR]` | Python 音频模块（音频处理.py）通过 Whisper/faster-whisper 转写 | speech 文本 |
| `[NLP]` | Python 文本模块通过 SnowNLP/Jieba 等做情感、关键词、敏感词、主题分类 | 情感分数、关键词、topicCategory |
| `[LLM]` | Python 调七牛云 LLM 产出（不可用时回退规则） | 六大维度的 evidences 描述、keyword、sentimentScore |
| `[融合]` | task_runner.py 把三模态分数加权聚合 | modalityFusion、comprehensiveRisks、radarByTime、averageRadarData |
| `[规则]` | task_runner.py 通过阈值/映射表确定的标签 | identityLabel、riskReason、actionSuggestion、actionDetail、topicSubCategory、isUniversityRelated |
| `[样式]` | Python 直接写死的前端展示色值/emoji | emotion.bgColor / textColor、sceneRecognition.icon |
| `[配置]` | 管理员维护的词库、任务挂载关系 | wordPacks（task_word_pack 关联） |
| `[写死]` | 常量值，不参与算法 | timeGranularity=5 |

## 关键边界提醒

- **`evidences[]` 的 `keyword` / `sentimentScore` 在 七牛云 LLM 不可用时由规则兜底**：六大维度的证据数据流是 `音频处理.py → 七牛云 LLM → task_runner.py 整合`；LLM 失败时会回退到 `generate_preliminary_evidences()`（音频处理.py:1914），但字段结构保持一致。
- **`evidences[].type` 取值是 `video | audio | text`**（这是六大维度卡片用的），别和 `timelineEvents[].modality` 的 `visual | speech | audio-effect` 混淆。
- **`videoInfo.description` 在数据库里叫 `aiDescription`**（TEXT 列），Java 在拼 VideoInfo 时重命名为 `description`。
- **`videoInfo.detectedKeywords / mainCharacter` 都属于"视频信息层"，但其实是算法产物**（前者来自 Jieba 关键词 + 高校词库，后者来自 OpenCV 场景+画质规则推断）；要在标注表里跟"系统元数据"明确区分。
- **`identity.identityLabel / riskReason / actionSuggestion / topicSubCategory / isUniversityRelated` 都是"阈值/映射规则"输出**，并非模型直接输出；标注同学只需给到大类结论，剩下交给规则。
- **`timelineData` 时间序列的粒度**固定 `timeGranularity = 5` 秒（写死常量），所以四条时间序列长度都等于 `ceil(duration / 5)`。
- **`videoInfo.thumbnailUrl`** 是 Java 用 FFmpeg 截取首帧后落 MinIO，与 Python 无关。
- **`wordPacks`** 不是分析结果的一部分，而是任务级配置：用户创建任务时挑选词包，Java 通过 `task_word_pack` 关联表反查后挂到 result 上返回。

## 字段→产出方对照速查

| 顶层字段 | 主要来源 | 备注 |
|---|---|---|
| `id / taskId / gmtCreated / reportPdfUrl` | `[系统]` | analysis_result 表的工程字段 |
| `videoInfo.videoId / videoUrl / fileName / duration / uploadSource / sourceUrl / thumbnailUrl` | `[系统]` + `[元数据]` | video 表 / MinIO |

| `timelineEvents` modality=`visual` | `[CV]` | YOLO-World 可选 + OpenCV 人脸/OCR 兜底 |
| `timelineEvents` modality=`speech` | `[ASR]+[NLP]+[样式]` | Whisper 转写 + 情感分数 + 写死色值 |

| `wordPacks` | `[配置]` | 管理员维护，task_word_pack 关联 |
| `isUniversityRelated`（顶层） | `[规则]` | university 融合分数 ≥65 |
